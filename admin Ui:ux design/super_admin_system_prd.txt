# Super Admin Management System PRD

## Core Identity
**Role:** Super Admin
**Environment:** Multitenant SaaS (biiQuiz)
**Visual Standard:** Enterprise-grade, clean, indigo-primary, data-dense.

## Screen List & Routes
1. **Dashboard** (`/super-admin/dashboard`): High-level platform health, pending approvals, and usage alerts.
2. **Enterprise Management** (`/super-admin/enterprises`): Directory of all institutes/tenants with resource usage tracking.
3. **Enterprise Detail** (`/super-admin/enterprises/:id`): Tabbed deep-dive into a specific tenant (Admins, Usage, Billing, Audit).
4. **Host Management** (`/super-admin/hosts`): Global educator directory with activity metrics.
5. **Student Management** (`/super-admin/students`): Global participant directory with performance filters.
6. **Quiz & Live Room Management** (`/super-admin/quizzes`, `/super-admin/rooms`): Oversight of active sessions and content.
7. **Analytics** (`/super-admin/analytics`): Growth trends, revenue summary, and platform-wide engagement.
8. **Plans & Packages** (`/super-admin/plans`): Configuration of subscription tiers and feature flags.
9. **Upgrade & Payment Verification** (`/super-admin/upgrade-requests`, `/super-admin/payments`): Manual billing workflow and proof-of-payment approval.
10. **Domains & AI Settings** (`/super-admin/domains`, `/super-admin/ai-settings`): Infrastructure and model configuration.
11. **Support & Audit Logs** (`/super-admin/support`, `/super-admin/audit-logs`): Ticket management and security compliance.
12. **Platform Settings** (`/super-admin/settings`): Global branding and configuration.

## Key UI Patterns
- **Usage Indicators:** Linear progress bars for hosts/students/quizzes limits.
- **Status Badges:** 'Verified', 'Pending', 'Suspended', 'Active'.
- **Manual Payment Flow:** QR-code based submission from Institute -> Transaction verification by Super Admin.
